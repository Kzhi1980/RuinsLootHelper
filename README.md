## 开始使用

1. 完整解压 ZIP，保留 `_internal` 文件夹，运行 **破晓装备助手.exe**。
2. 启动游戏并进入角色。助手会记住游戏路径，自动连接当前会话。
3. 在 **装备筛选** 中设置词条、上技能、下技能，点击右下角 **保存设置**。
4. 需要进阶辅助时，再到 **进阶辅助 → 安装 / 更新组件**，安装后重启游戏。

装备筛选可以独立使用。自动锁定与自动回收上下放在同一组，先锁定达标装备，再回收。

## 0.3.11 的变化

- 同步 Steam 构建 25669660：装备库增至 559 件，新增 10 件 T7 和五个套装名称；T7 支持品质、装备库、属性门槛及上技能筛选。
- 适配新版掉落屏蔽接口，保留已核实的旧接口支持；未知接口停止扩展屏蔽并报告状态。
- 新增雪地柔和配色、旋风斩光效减弱／隐藏、单人或自己开房时约 1 秒快速回城，均默认关闭。
- 修复雪地换色继续调用失效材质的问题；切换主题及恢复前重新核对当前材质。原生主循环改为游戏线程执行，移除异步 Lua 轮询。
- 保留此前状态文件占用恢复、启动报错修复、自动锁定及回收保护，更新不会自动勾选新装备或修改门槛。
- **同一条规则内全部条件同时满足，不同启用规则满足任意一条即可保留**。例如“完美＋T6＋霄引＋魔法上限 ≥48”必须全部达标。

保留自动拾取、背包标记、自动回收、自动开门和八卦入口提示。313 项自动检查通过；本轮修复后的真实进图、换色及切图稳定性仍待验证，详见[验证与限制](docs/validation.md)。

自动开门条件：等级 ≥50，或额外掉落率与额外极品率均 ≥300%。八卦提示在地图放大时隐藏，加入他人房间时可能读不到入口。
