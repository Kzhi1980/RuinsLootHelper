## 开始使用

1. 完整解压 ZIP，保留 `_internal` 文件夹，运行 **破晓装备助手.exe**。
2. 启动游戏并进入角色。助手会记住游戏路径，自动连接当前会话。
3. 在 **装备筛选** 中设置词条、上技能、下技能，点击右下角 **保存设置**。
4. 需要进阶辅助时，再到 **进阶辅助 → 安装 / 更新组件**，安装后重启游戏。

装备筛选可以独立使用。自动锁定与自动回收上下放在同一组，先锁定达标装备，再回收。

## 0.3.12 的变化

- 修复旋风斩选择减弱／隐藏后，技能直接生成的光圈仍显示的问题。
- 新增独立的“半月斩特效”开关，默认关闭；覆盖主动技能和普攻／自动攻击触发的半月光效。
- 保留攻击动作、技能伤害及命中范围，关闭选项后恢复正常显示。
- 保留 T7 数据、559 件装备库和现有筛选、锁定、回收规则；不会自动勾选装备或修改门槛。

旋风斩与普攻自动半月的隐藏效果已由用户实测确认。雪地柔和配色的闪烁问题本次未处理，出现闪烁时可关闭该选项；完整验证范围见[验证与限制](docs/validation.md)。

装备保留规则仍是：**同一条规则内全部条件同时满足，不同启用规则满足任意一条即可保留**。例如“完美＋T6＋霄引＋魔法上限 ≥48”必须全部达标。

自动开门条件：等级 ≥50，或额外掉落率与额外极品率均 ≥300%。八卦提示在地图放大时隐藏，加入他人房间时可能读不到入口。
